# Auto Curation AI

A modern SaaS web app concept for creators to upload long-form videos and auto-generate viral-ready short clips for TikTok, Reels, and Shorts.

## Pages
- Landing page (`index.html`)
- Dashboard (`dashboard.html`)
- Upload flow (`upload.html`)
- AI analysis results (`analysis.html`)
- Clip editor (`editor.html`)
- Pricing (`pricing.html`)
- Auth (`login.html`, `signup.html`)

## Run locally
Open `index.html` directly, or run:

```bash
python -m http.server 8000
```
